# 🚗 Trip · 个人自驾旅行路书宇宙

> 记录与规划个人自驾旅行的综合仓库。基于纯静态 Web 技术与高德地图 JS API 构建的高颜值、零依赖、沉浸式互动路书。

---

## 🗺️ 仓库规划与多项目架构 (Multi-Project Architecture)

本仓库采用集中式旅行路书管理模式（Monorepo）。涵盖国内自驾大环线与海外城市深度漫行：

```text

├── trip-map/                   # 【项目1：西行计划 · 丝路自驾】(高德地图 JS API)
│   ├── index.html              # 核心生产源码（单文件 SPA）
│   └── assets/images/          # 高清文化背景与素材
├── kl-trip/                    # 【项目2：吉隆坡漫行 · 城市路书】(Google Maps JS API)
│   ├── index.html              # 核心生产源码（单文件 SPA）
│   └── assets/images/          # 城市天际线与素材
├── index.html                  # 丝路自驾路书（根目录镜像发布入口）
├── progress.md                 # 西行计划开发手册与里程碑
├── progress-kl.md              # 吉隆坡漫行开发手册与里程碑
├── 路书第二层级规划.md         # 丝路自驾深度攻略与元数据库
├── 吉隆坡第二层级规划.md       # 吉隆坡美食/机位/交通深度元数据库
├── GEMINI.md                   # 自动化开发指南与代码/同步铁律
└── README.md                   # 本文件（仓库总览与部署索引）
```

## 🌟 当前核心项目：西行计划 · 丝路自驾路书

### 1. 路线概览
- **全长里程**：约 4,300+ 公里
- **自驾周期**：10 ~ 12 天
- **经典途经**：西安 ➔ 兰州 ➔ 西宁 ➔ 青海湖 ➔ 德令哈/柴达木 ➔ 敦煌（莫高窟、鸣沙山月牙泉）➔ 瓜州 ➔ 嘉峪关 ➔ 张掖七彩丹霞 ➔ 武威 ➔ 中卫（沙坡头）➔ 西安

### 2. 核心架构与技术特色
- **免构建单文件 (Zero-Build)**：坚持单文件 HTML/CSS/JS、零后端、免打包静态架构，可直接托付于任意静态 CDN（如 Cloudflare Pages、GitHub Pages）。
- **苹果液态玻璃 (Apple Liquid Glass)**：全屏地图满铺打底，所有面板与悬浮控件均基于高斯模糊磨砂滤镜、边缘折射高光与深邃悬浮投影。
- **高德地图 JS API 2.0 深度集成**：
  - 浅色标准公路矢量图与高清卫星影像 `🛰️` 悬浮无缝切换；
  - 行程日程卡片联动：点击“地图查看路线”自动智能调焦并高亮当天路段；
  - 沿途打卡点、补给站、测速预警与限速提示标记。
- **二级深度文化抽屉**：
  - 莫高窟特窟预约攻略、张掖丹霞摄影机位、高海拔行车与无人区自驾注意事项。

## 🌟 核心项目二：吉隆坡漫行 · 城市旅行互动路书

### 1. 路线与看点
- **旅行周期**：4 ~ 5 天
- **经典途经**：KLCC 双子塔 ➔ 茨厂街百年早茶 ➔ 独立广场与默迪卡 118 ➔ 黑风洞 272 级彩虹阶梯 ➔ Heli Lounge Bar 停机坪落日 ➔ 布城水上粉红清真寺 ➔ 柏威年十号胡同老字号
- **核心出行方式**：Grab 专车 + LRT/MRT 轨道交通 + 机场快线 KLIA Ekspres

### 2. 技术特色
- **Google Maps JavaScript API**：国际标准 WGS-84 原生坐标，定制深邃黑曜石暗夜街道风格。
- **热带雷雨与高峰避堵熔断**：三段式时间弹性检视系统，科学调度午后暴雨室内备选方案。
- **全要素 Grab 与谷歌导航直达**：半屏抽屉长图文内嵌 Google Maps Universal Links 与 Grab 唤起协议。
- **双币种 AA 记账器**：支持马币 (MYR) 与人民币 (CNY) 实时汇率折算与多人分摊。
