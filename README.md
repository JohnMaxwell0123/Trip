# 🚗 Trip · 个人自驾旅行路书宇宙

> 记录与规划个人自驾旅行的综合仓库。基于纯静态 Web 技术与高德地图 JS API 构建的高颜值、零依赖、沉浸式互动路书。

---

## 🗺️ 仓库规划与多项目架构 (Multi-Project Architecture)

本仓库采用集中式旅行路书管理模式（Monorepo）。目前以**西行计划（丝路自驾）**为首发核心项目；未来新增自驾路线（如云南大环线、北疆自驾等）将按子目录规范扩充，形成个人旅行自驾合集。

```text
Trip/ (仓库根目录)
├── index.html                  # 丝路自驾路书（根目录镜像发布入口）
├── trip-map/                   # 丝路自驾核心工作目录
│   ├── index.html              # 核心生产源码（单文件 SPA）
│   └── assets/images/          # 高清文化背景、敦煌飞天与视觉素材
├── assets/images/              # 根目录素材镜像
├── progress.md                 # 西行计划开发里程碑与技术决策全景
├── GEMINI.md                   # 自动化开发指南与代码/同步铁律
├── 路书第二层级规划.md         # 丝路全线各节点历史文化与自驾攻略知识库
└── README.md                   # 本文件（仓库总览与部署索引）
```

## 🌟 当前核心项目：西行计划 · 丝路自驾路书

### 1. 路线概览
- **全长里程**：约 4,300+ 公里
- **自驾周期**：10 ~ 12 天
- **经典途经**：西安 ➔ 兰州 ➔ 西宁 ➔ 青海湖 ➔ 德令哈/柴达木 ➔ 敦煌（莫高窟、鸣沙山月牙泉）➔ 瓜州 ➔ 嘉峪关 ➔ 张掖七彩丹霞 ➔ 武威 ➔ 中卫（沙坡头）➔ 西安

### 2. 核心架构与技术特色
- **免构建单文件 (Zero-Build)**：坚持单文件 HTML/CSS/JS、零后端、免打包静态架构，可直接托付于任意静态 CDN（如 Cloudflare Pages、GitHub Pages）。
- **苹果液态玻璃 (Apple Liquid Glass)**：全屏地图满铺打底，所有面板与悬浮控件均基于高斯模糊磨砂滤镜、边缘折射高光与深邃悬浮投影。
- **高德地图 JS API 2.0 深度集成**：
  - 浅色标准公路矢量图与高清卫星影像 `🛰️` 悬浮无缝切换；
  - 行程日程卡片联动：点击“地图查看路线”自动智能调焦并高亮当天路段；
  - 沿途打卡点、补给站、测速预警与限速提示标记。
- **二级深度文化抽屉**：
  - 莫高窟特窟预约攻略、张掖丹霞摄影机位、高海拔行车与无人区自驾注意事项。

## 🚀 Cloudflare Pages 自动部署指南 (CI/CD)

本项目与 Cloudflare Pages 已深度打通，实现 **Git Push ➔ 自动触发全球边缘部署**：

- **正式生产发布站点**：[https://trip-cts.pages.dev](https://trip-cts.pages.dev)
- **CI/CD 触发机制**：向 `main` 分支推入任何 Commit，Cloudflare Pages 将在 15~25 秒内自动完成全球边缘节点部署。

### 构建与发布参数规范：
- **关联仓库**：`JohnMaxwell0123/Trip`
- **生产分支 (Production Branch)**：`main`
- **框架预设 (Framework preset)**：`None`（无）
- **构建命令 (Build command)**：**留空**（零打包构建，免编译静态架构）
- **构建输出目录 (Build output directory)**：`trip-map`（或 `/`）
