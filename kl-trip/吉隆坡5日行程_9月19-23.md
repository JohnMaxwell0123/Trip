## 🔤 二、地名小词典（看懂当地地名）

马来西亚地名以马来文拼写，看懂这几个词根就能自己认路了：

| 马来文 | 含义 | 常见组合 |
|---|---|---|
| **Jalan**（常缩写成 Jln） | 路、街 | Jalan Alor = 亚罗街；Jalan Petaling = 茨厂街 |
| **Lorong** | 巷、小路 | Lorong Raja Uda 1 = 你住的酒店那条街 |
| **Bukit** | 山丘 | Bukit Bintang = 武吉免登（"星光山"，商圈） |
| **Kampung** | 村庄 | Kampung Baru = 甘榜峇鲁（马来族老社区，你住这） |
| **Masjid** | 清真寺 | Masjid Negara = 国家清真寺 |
| **Pasar** | 市场 | Pasar Seni = 中央艺术坊（"艺术市场"）；Pasar Malam = 夜市 |
| **Menara** | 塔 | Menara Kuala Lumpur = 吉隆坡塔 |
| **Batu** | 石头 | Batu Caves = 黑风洞（"石洞"） |
| **Dataran** | 广场 | Dataran Merdeka = 独立广场 |
| **Taman** | 公园、花园 | Taman Tasik Perdana = 佩尔达纳湖滨公园 |
| **Sentral / Terminal** | 中央车站、总站 | KL Sentral = 中央车站；TBS = 南部综合总站（去马六甲、机场） |
| **Persiaran** | 大道 | Persiaran KLCC = 双子塔旁的地铁站名 |
| **KLCC** | Kuala Lumpur City Centre | 双子塔那一整片区域都叫 KLCC |

> 点餐小词：**Nasi** = 饭，**Lemak** = 椰浆，**Ayam** = 鸡，**Ikan** = 鱼，**Kopi** = 咖啡，**Teh** = 茶，**Sambal** = 辣酱，**Kurang manis** = 少甜。
